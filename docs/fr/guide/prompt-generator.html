    #Générateur de prompt

    Cette page prépare une requête complète pour un modèle de langage : votre description de l'installation, les règles du format de scénario, les catalogues des comportements et des DPT, et en option un exemple de départ. Collez le texte généré dans l'assistant de votre choix, puis collez sa réponse ci-dessous pour la vérifier. Rien n'est envoyé depuis cette page ; tout s'exécute dans le navigateur. Voir générer avec un modèle de langage pour la méthode et ses limites.

    #1. Décrire l'installation

    #2. Copier la requête

    #3. Vérifier la réponse

    Ouvrir dans le designer

    Répétez les étapes 2 et 3 avec la requête de correction jusqu'à ce que le scénario soit valide, puis ouvrez-le dans le designer pour examiner le schéma. La validation confirme que le scénario est cohérent ; elle ne confirme pas qu'il correspond à l'installation voulue.
