    Référence

    #Scénario JSON (format 2)

    Cette référence est générée à partir du schéma de rédaction schema/scenario-v2.schema.json. Le composant valide en plus les références entre objets, canaux, adresses et ports des comportements. Voir les codes d'erreur.

    #Racine

    Scénario BusDiagram, format 2. Généré par npm run schema.

    Champ Type Obligatoire Description
    $schema chaîne Chemin du schéma pour la complétion dans l'éditeur ; ignoré par BusDiagram.
    formatVersion 2 oui Version du format : 2, la seule prise en charge.
    title chaîne Titre affiché dans la barre d'outils.
    description chaîne Description affichée sous la barre d'outils.
    lines liste de Ligne oui Lignes à paire torsadée. Plusieurs lignes ajoutent des coupleurs de ligne et des lignes principales ; plusieurs zones ajoutent une ligne de zone (backbone).
    clock objet Horloge simulée : date et heure locales au démarrage de la simulation, et accélération. Les horloges maîtres, les programmateurs et les plages horaires l'utilisent.
    rooms liste de Pièce Pièces : état thermique partagé par les thermostats, contacts de fenêtre, radiateurs et ventilo-convecteurs qui y sont affectés.
    topology objet Niveaux de la topologie et réglages des coupleurs. Sans ce champ, une ligne principale apparaît avec deux lignes dans une zone, et une ligne de zone avec deux zones.
    ipRouter objet Ancien réglage d'un réseau IP à un seul routeur ; préférez topology.ip. L'adresse doit être celle d'un coupleur (A.L.0 ou A.0.0).
    groupRanges liste de objet Noms des groupes principaux ("1") et des groupes médians ("1/2"), affichés dans l'arborescence des adresses de groupe du designer.
    groupAddresses liste de Adresse de groupe Adresses de groupe déclarées : noms et DPT affichés dans le moniteur et hérités par les objets associés.
    devices liste de Appareil oui Appareils dans l'ordre du câble sur leur ligne ; l'ordre détermine le délai de propagation.
    options objet Réglages initiaux de la simulation.

    #Ligne

    Ligne TP.

    Champ Type Obligatoire Description
    address chaîne (format vérifié) oui Adresse de ligne sous la forme zone.ligne, comme 1.1 ; valeurs 1 à 15. Les lignes principales et la ligne de zone viennent de topology.
    name chaîne Nom affiché sous le bus, par exemple « Ligne d'exemple ».
    extension objet Extension de ligne : répéteur ou coupleur de segment vers un segment en aval.
    powerSupply Alimentation Alimentation bus de la ligne, dessinée sur le schéma.

    #Alimentation

    Alimentation KNX avec self. Dessinée sur le schéma ; la charge du bus n'est pas calculée.

    Champ Type Obligatoire Description
    name chaîne Nom, comme une référence de produit.
    currentMa nombre Courant nominal en mA, comme 160, 320, 640 ou 1280.

    #Pièce

    Modèle thermique de la pièce : pertes vers la température extérieure plus l'apport des équipements ; une fenêtre ouverte augmente les pertes.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant utilisé par les affectations aux pièces.
    name chaîne Nom affiché ; par défaut l'identifiant.
    temperatureC nombre Température intérieure initiale en °C ; 20 par défaut.
    outsideTemperatureC nombre Température extérieure en °C ; 5 par défaut.
    windowOpen booléen Fenêtre ouverte au départ.
    timeConstantMs entier Constante de temps des pertes thermiques en millisecondes simulées ; 300 000 ms par défaut.

    Voir le guide CVC pour le modèle thermique et des exemples.

    #Adresse de groupe

    Adresse de groupe déclarée.

    Champ Type Obligatoire Description
    address chaîne (format vérifié) oui Adresse de groupe à trois niveaux (principal/médian/sous-groupe), comme 1/1/1.
    name chaîne Rôle affiché dans le moniteur et les infobulles.
    dpt DPT DPT hérité par les objets qui ne déclarent pas le leur.

    #Appareil

    Appareil KNX avec une adresse individuelle, des objets, des touches, des entrées et des canaux.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant unique dans le scénario.
    name chaîne Nom affiché sur la carte de l'appareil ; par défaut l'identifiant.
    address chaîne (format vérifié) Adresse individuelle sous la forme zone.ligne.appareil ; sa ligne doit être déclarée.
    kind chaîne oui Type d'appareil, en description libre (buttonInterface, switchActuator, display…). Seul un comportement qui documente une valeur lui donne un effet : display/v1 dessine "supervisor" comme un logiciel de supervision.
    behavior "switchActuator/v1", "shutterActuator/v1", "display/v1", "passive/v1", "presenceDetector/v1", "usbInterface/v1", "dimmerActuator/v1", "daliGateway/v1", "roomThermostat/v1", "heatingActuator/v1", "windowContact/v1", "temperatureSensor/v1", "logicGate/v1", "weatherStation/v1", "airQualitySensor/v1", "clockMaster/v1", "timeSwitch/v1", "systemGateway/v1", "energyMeter/v1", "buttonInterface/v1", "alarmModule/v1" ou chaîne (format vérifié) oui Identifiant versionné du comportement enregistré de l'appareil.
    parameters objet Paramètres de l'appareil définis par son comportement.
    medium "TP", "IP" Support de communication : TP par défaut, ou IP sur le réseau topology.ip (un superviseur sur le réseau IP indique "IP").
    room chaîne (format vérifié) Identifiant de la pièce affectée ; thermostats, contacts de fenêtre et sondes de température observent cette pièce.
    inFilterTables booléen false : ne pas inclure cet appareil virtuel dans les tables de filtrage des coupleurs.
    downstream booléen Appareil sur le segment en aval d'une extension de ligne.
    description chaîne Explication affichée quand on sélectionne la carte de l'appareil.
    objects liste de Objet de communication oui Objets de communication dans l'ordre de la carte de l'appareil.
    buttons liste de Touche Touches (bouton-poussoir, capteur).
    inputs liste de Entrée numérique Entrées numériques.
    channels liste de Canal Canaux de l'actionneur (sorties).

    Les paramètres propres à chaque comportement figurent dans la référence des comportements.

    #Objet de communication

    Objet de communication d'un appareil.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant unique dans l'appareil ; les touches, entrées et voyants peuvent s'y référer.
    name chaîne Nom affiché sur la carte de l'appareil ; par défaut l'identifiant.
    ga chaîne (format vérifié) ou liste de chaîne (format vérifié) oui Adresses de groupe associées : la première est l'adresse d'émission ; les autres sont seulement en réception. Une liste vide laisse l'objet sans association.
    dpt DPT DPT de l'objet ; par défaut le DPT de sa première adresse de groupe déclarée.
    port "switch", "status", "scene", "forced", "lock", "logic"… oui Rôle de l'objet dans le comportement de l'appareil.
    channel chaîne Identifiant du canal dans l'appareil ; obligatoire pour les ports d'actionneur.
    value nombre ou null Valeur initiale (zéro par défaut ; inconnue pour un port d'affichage).
    flags objet oui Indicateurs : C communication, R lecture, W écriture, T transmission, U mise à jour, I lecture à l'initialisation.
    priority "low", "normal", "urgent" Priorité de transmission des trames envoyées par l'objet (low par défaut) ; la priorité système est réservée à la gestion.

    #Touche

    Touche dessinée sur la carte de l'appareil ; utilisez press ou une paire short/long.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant unique parmi les touches et entrées de cet appareil.
    label chaîne Libellé de la touche ; par exemple « Touche 2 · Descendre » affiche Touche 2 en évidence.
    icon "on", "off", "toggle", "up", "down", "updown"… Icône déduite de l'action si elle est omise.
    press objet Action immédiate à l'appui ; ne peut pas être combinée avec short/long.
    short objet Action au relâchement avant le seuil d'appui long.
    long objet Action après le seuil d'appui long (0,5 s par défaut).
    release objet Action au relâchement après un appui long, comme l'arrêt d'une variation DPT 3.007.
    led chaîne Objet dont la valeur allume le voyant de la touche.

    Une action de touche (press, short ou long) désigne un objet et lui donne un nombre ou "toggle", par exemple { "object": "key1", "value": 1 }.

    #Entrée numérique

    Entrée numérique dessinée sur la carte de l'appareil.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant unique parmi les touches et entrées de cet appareil.
    type "number" oui Le seul type d'entrée est number.
    label chaîne Libellé affiché au-dessus de l'entrée.
    object chaîne oui Objet d'entrée avec une adresse de groupe ; écrit et transmis à la validation.
    min nombre Valeur minimale ; par défaut le minimum du DPT.
    max nombre Valeur maximale ; par défaut le maximum du DPT.
    step nombre Pas de saisie ; 1 par défaut.

    #Canal

    Canal de sortie de l'actionneur ; déclarez les canaux matériels même inutilisés.

    Champ Type Obligatoire Description
    id chaîne (format vérifié) oui Identifiant unique dans l'appareil, utilisé par ses objets de communication.
    label chaîne Libellé du canal : un libellé de charge comme L1 (« unused » pour une sortie non raccordée), ou le nom d'une entrée.
    keyLabel chaîne Texte écrit sur le bouton-poussoir câblé à une entrée de contact (interface de boutons-poussoirs), dessiné sur sa touche ; par défaut la touche affiche le libellé.
    keyContact "normallyOpen", "normallyClosed" Contact du bouton-poussoir câblé à une entrée de contact : normalement ouvert (se ferme à l'appui, par défaut) ou normalement fermé.
    parameters objet Paramètres de canal propres au comportement, comme une minuterie ou une durée de course.
    initialState objet État applicatif initial du canal.
    equipment Équipement ou liste de Équipement ou null Équipement raccordé : une charge, une liste de charges commutées ensemble, ou null pour une sortie libre sans charge dessinée.
    scenes objet Préréglages de scènes : le numéro de scène 1 à 64 correspond à un état de relais ou à une position de volet.

    #Équipement

    Équipement non KNX raccordé à une sortie de canal.

    Champ Type Obligatoire Description
    type "lamp", "shutter", "dimmableLamp", "daliGroup", "radiator", "fanCoil", "fan", "appliance", "waterHeater", "heatPump", "siren" ou chaîne (format vérifié) oui Type d'équipement : lamp, shutter, ou un type enregistré par une extension.
    name chaîne Nom de la charge, comme « Plafonnier » ; affiché sur le schéma et dans le designer.
    view chaîne Type de vue ; par défaut le type d'équipement, comme la vue ledStrip d'une extension.
    room chaîne (format vérifié) Identifiant de la pièce chauffée ou refroidie, pris dans rooms ; obligatoire pour un radiateur, un ventilo-convecteur ou une pompe à chaleur.
    parameters objet Paramètres de l'équipement, comme actualTravelTimeMs pour un volet.
    initialState objet État physique initial, comme positionPct pour un volet.
