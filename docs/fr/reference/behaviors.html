    #Comportements

    #switchActuator/v1

    Actionneur de commutation : chaque canal commande un relais ; minuterie, retour d'état et mesure de puissance et d'énergie facultatifs. Commande de sortie : switch.

    Ports

    Port DPT Canal Rôle
    switch 1.001 obligatoire Commande de commutation de la sortie (0 = arrêt, 1 = marche).
    status 1.001 obligatoire État du relais, envoyé après chaque changement effectif.
    scene 17.001, 18.001 facultatif (tous les canaux s'il est omis) numéro de scène (17.001), ou commande de scène (18.001) dont le bit d'apprentissage mémorise l'état actuel
    forced 2.001 obligatoire Forçage prioritaire (2 = forcer à l'arrêt, 3 = forcer en marche, 0 ou 1 = fin du forçage).
    lock 1.001 obligatoire 1 verrouille la sortie dans l'état défini par lockStart, 0 la déverrouille (afterLock)
    logic 1.001 obligatoire combiné avec la commande de commutation par logicOperation (ET ou OU)
    power 14.056, 9.024 obligatoire puissance électrique consommée par la charge du canal : W avec 14.056, kW avec 9.024
    energy 13.010, 13.013 obligatoire énergie active comptée pour le canal, envoyée cycliquement : Wh avec 13.010, kWh avec 13.013
    totalPower 14.056, 9.024 aucune somme des puissances de tous les canaux : W avec 14.056, kW avec 9.024
    powerLimit 1.005, 1.001 aucune 1 quand la puissance totale atteint powerLimitW, 0 après l'hystérésis (délestage)
    intrusionAlarm 1.005, 1.001 facultatif (tous les canaux s'il est omis) 1 fait clignoter la sortie et ignorer les commandes ; 0 termine l'alarme (afterAlarm). Sans canal, s'applique à tous les canaux.
    fireAlarm 1.005, 1.001 facultatif (tous les canaux s'il est omis) 1 force la sortie en marche et ignore les commandes, en priorité sur l'intrusion ; 0 termine l'alarme. Sans canal, s'applique à tous les canaux.

    Paramètres de l'appareil (parameters)

    Paramètre Type Défaut Contraintes Description
    meterIntervalMs integer 5000 ≥ 1000 Envoi cyclique des valeurs de puissance et d'énergie (ms), pour les canaux qui ont des objets de mesure.
    powerSendDeltaW number 10 ≥ 0 Envoyer une valeur de puissance quand elle change d'au moins ce nombre de watts.
    energyTimeScale number 60 > 0 Vitesse de comptage de l'énergie : 60 compte une seconde simulée comme une minute, pour que le compteur avance visiblement ; 1 compte en temps réel.
    powerLimitW number 0 ≥ 0 Puissance totale (W) des sorties de l'actionneur à partir de laquelle l'objet powerLimit est activé, pour le délestage (0 le désactive).
    sheddingTimeMs integer 20000 ≥ 0 Une sortie délestée est réenclenchée après ce délai si sa commande le demande toujours ; elle est délestée à nouveau si la limite est toujours dépassée.
    powerLimitHysteresisW number 50 ≥ 0 L'objet powerLimit est remis à zéro sous limite − hystérésis (W).

    Paramètres de canal (channels[].parameters)

    Paramètre Type Défaut Contraintes Description
    timerMs integer null null > 0
    timerRetrigger string "restart" "restart" (Relance), "none" (Sans effet), "add" (Prolonge) Quand 1 est reçu pendant une minuterie : restart relance une période complète, none l'ignore, et add prolonge la période (jusqu'à cinq fois).
    timerWarningMs integer 0 ≥ 0 Durée avant la fin de la minuterie à laquelle la sortie s'ouvre brièvement pendant une seconde, en guise d'avertissement (0 désactive l'avertissement).
    timerOffAllowed boolean true Autoriser une écriture de 0 à éteindre avant la fin de la minuterie ; sinon l'ignorer.
    loadShedding boolean false Éteindre cette sortie tant que la limite de puissance totale de l'actionneur est dépassée (délestage).
    relayMode string "normallyOpen" "normallyOpen" (Normalement ouvert), "normallyClosed" (Normalement fermé) normallyOpen ferme le contact quand le canal est en marche ; normallyClosed le ferme quand le canal est à l'arrêt, si bien que la charge est alimentée quand l'état de commutation vaut 0. Le retour d'état renvoie l'état de commutation, pas celui du contact.
    statusDelayMs integer 300 ≥ 0 Délai avant l'envoi du retour d'état (ms).
    onDelayMs integer 0 ≥ 0 Délai entre un 1 sur l'objet de commutation et l'enclenchement (0 : immédiat). Un 0 reçu entre-temps l'annule ; scènes, forçage et verrouillage agissent immédiatement.
    offDelayMs integer 0 ≥ 0 Délai entre un 0 sur l'objet de commutation et le déclenchement (0 : immédiat). Un 1 reçu entre-temps l'annule.
    lockStart string "unchanged" "unchanged" (Inchangé), "on" (Marche), "off" (Arrêt) État de la sortie quand l'objet de verrouillage reçoit 1 ; pendant le verrouillage, les commandes sont mémorisées sans effet. Le forçage est prioritaire sur le verrouillage.
    afterLock string "lastCommand" "lastCommand" (Dernière commande), "previous" (État précédent), "unchanged" (Inchangé), "on" (Marche), "off" (Arrêt), "toggle" (Inverser) État quand l'objet de verrouillage reçoit 0 : suivre la dernière commande reçue pendant le verrouillage, rétablir l'état d'avant le verrouillage, garder l'état actuel, enclencher, déclencher ou inverser.
    logicOperation string "and" "and" (ET : en marche quand la commande et l'objet logique valent 1), "or" (OU : en marche quand la commande ou l'objet logique vaut 1) Combinaison de la commande de commutation avec l'objet logique (par exemple une validation venant d'un détecteur de présence). Tant que l'objet logique n'a reçu aucune valeur, la commande agit seule.
    sceneLearning boolean true Un télégramme de commande de scène avec le bit d'apprentissage (DPT 18.001) mémorise l'état actuel de la sortie comme scène ; il remplace le préréglage configuré jusqu'au redémarrage de la simulation.
    busFailure string "unchanged" "unchanged" (Inchangé), "off" (Arrêt), "on" (Marche) État de la sortie à la coupure de la tension bus ; le relais reste ensuite tel quel jusqu'au retour de la tension.
    busRecovery string "previous" "previous" (État avant la coupure), "off" (Arrêt), "on" (Marche) État de la sortie au retour de la tension bus ; le retour d'état est alors envoyé.
    blinkMs integer 1000 ≥ 1000 Durée pendant laquelle le contact reste fermé, puis ouvert, quand l'alarme intrusion fait clignoter la sortie ; attention à la durée de vie du relais en commutation.
    afterAlarm string "lastCommand" "lastCommand" (Dernière commande), "previous" (État précédent), "unchanged" (Inchangé), "on" (Marche), "off" (Arrêt) État à la fin de la dernière alarme (incendie, intrusion) : suivre la dernière commande reçue pendant l'alarme, rétablir l'état d'avant, rester en marche, enclencher ou déclencher.
    afterForcing string "lastCommand" "lastCommand" (Dernière commande), "previous" (État précédent), "unchanged" (Inchangé), "on" (Marche), "off" (Arrêt), "toggle" (Inverser) État à la fin d'un forçage prioritaire : suivre la dernière commande reçue pendant le forçage, rétablir l'état précédent, garder l'état forcé, enclencher, déclencher ou inverser l'état forcé.

    État initial du canal (channels[].initialState)

    Paramètre Type Défaut Contraintes Description
    on boolean false État de commutation du canal au démarrage de la simulation.

    #shutterActuator/v1

    Actionneur de volets sans capteur : position estimée d'après la durée de course configurée. Commande de sortie : motor.

    Ports

    Port DPT Canal Rôle
    move 1.008 obligatoire Montée/descente : 0 monte vers 0 %, 1 descend vers 100 %.
    stopStep 1.007 obligatoire Arrêt pendant un mouvement ; sinon un pas de stepPct (0 vers le haut, 1 vers le bas).
    positionCommand 5.001 obligatoire Position cible en pourcentage.
    positionStatus 5.001 obligatoire Position estimée, envoyée après l'arrêt.
    scene 17.001, 18.001 facultatif (tous les canaux s'il est omis) numéro de scène (17.001), ou commande de scène (18.001) dont le bit d'apprentissage mémorise la position actuelle
    slatCommand 5.001 obligatoire angle des lamelles (0 % ouvert, 100 % fermé) d'un store à lamelles
    slatStatus 5.001 obligatoire angle des lamelles estimé, envoyé après l'arrêt
    windAlarm 1.005, 1.001 facultatif (tous les canaux s'il est omis) 1 déclenche l'alarme vent (windReaction, montée par défaut) : les commandes sont ignorées jusqu'à 0 ; sans canal, s'applique à tous les canaux
    lock 1.001 obligatoire 1 verrouille la sortie : les commandes sont ignorées, avec les réactions lockStart et afterLock ; par défaut, les alarmes météo restent prioritaires (safetyPriority).
    rainAlarm 1.005, 1.001 facultatif (tous les canaux s'il est omis) 1 déclenche l'alarme pluie (rainReaction) ; 0 la termine
    frostAlarm 1.005, 1.001 facultatif (tous les canaux s'il est omis) 1 déclenche l'alarme gel (frostReaction) ; 0 la termine
    forced 2.008, 2.001 obligatoire 3 force la descente, 2 force la montée ; 0 ou 1 termine le forçage (afterForcing). Par défaut, les alarmes météo et le verrouillage restent prioritaires (safetyPriority).
    recallPosition12 1.022, 1.001, 1.002 obligatoire 0 va à la position mémorisée 1, 1 à la position mémorisée 2
    recallPosition34 1.022, 1.001, 1.002 obligatoire 0 va à la position mémorisée 3, 1 à la position mémorisée 4
    storePosition12 1.001, 1.002 obligatoire 0 mémorise la position actuelle comme position 1, 1 comme position 2
    storePosition34 1.001, 1.002 obligatoire 0 mémorise la position actuelle comme position 3, 1 comme position 4
    upperLimit 1.002, 1.001 obligatoire 1 quand le volet est estimé en haut (0 %), envoyé à chaque changement
    lowerLimit 1.002, 1.001 obligatoire 1 quand le volet est estimé en bas (100 %), envoyé à chaque changement

    Paramètres de canal (channels[].parameters)

    Paramètre Type Défaut Contraintes Description
    estimatedTravelTimeMs (obligatoire) integer > 0 Durée de course configurée dans l'actionneur (ms) : en descente, et en montée sauf si estimatedTravelTimeUpMs est défini.
    estimatedTravelTimeUpMs integer > 0 Durée de course en montée configurée dans l'actionneur (ms), quand elle diffère de la descente ; beaucoup d'actionneurs prennent des durées séparées car un volet monte plus lentement qu'il ne descend.
    startDelayMs integer 300 ≥ 0 Délai avant de démarrer ou d'inverser le mouvement (ms).
    statusDelayMs integer 300 ≥ 0 Délai avant l'envoi du retour de position (ms).
    slatTravelMs integer 0 ≥ 0 Store à lamelles : durée configurée pour que les lamelles passent d'ouvertes à fermées (ms). Un mouvement oriente d'abord les lamelles ; un appui court à l'arrêt les oriente de slatStepPct. 0 pour un volet roulant sans lamelles.
    slatStepPct number 20 ≥ 1 ; ≤ 100 Variation de l'angle des lamelles pour un appui court à l'arrêt (%).
    stepPct number 0 ≥ 0 ; ≤ 100 Pas de position pour une commande arrêt/pas reçue à l'arrêt par un volet sans lamelles (%). 0 (par défaut) : aucun mouvement, comme dans la fonction arrêt/pas de KNX, où le pas oriente les lamelles ; certains actionneurs déplacent plutôt un volet roulant de cette valeur.
    endSupplementPct number 0 ≥ 0 ; ≤ 50 Durée de course supplémentaire vers 0 % ou 100 %, en pourcentage de la course complète. Le moteur tourne même si l'estimation est déjà en butée ; la fin de course recale l'estimation (souvent 5 à 10 % sur un vrai actionneur).
    invertOutput boolean false Inverser les sorties montée et descente pour compenser un moteur câblé à l'envers (paramètre wiringReversed du volet). Sans un tel câblage, l'activer fait aller le volet à l'inverse des commandes.
    sceneLearning boolean true Un télégramme de commande de scène avec le bit d'apprentissage (DPT 18.001) mémorise la position estimée actuelle comme scène ; il remplace le préréglage configuré jusqu'au redémarrage de la simulation.
    windReaction string "up" "up" (Montée), "down" (Descente), "stop" (Arrêt), "none" (Aucun mouvement) Mouvement au début de l'alarme vent ; les commandes sont ensuite ignorées jusqu'à sa fin.
    rainReaction string "up" "up" (Montée), "down" (Descente), "stop" (Arrêt), "none" (Aucun mouvement) Mouvement au début de l'alarme pluie (un store banne ou un store est généralement remonté).
    frostReaction string "none" "up" (Montée), "down" (Descente), "stop" (Arrêt), "none" (Aucun mouvement) Mouvement au début de l'alarme gel ; un volet gelé est généralement laissé où il est.
    alarmPriority string "wind,rain,frost" "wind,rain,frost" (Vent > Pluie > Gel), "wind,frost,rain" (Vent > Gel > Pluie), "rain,wind,frost" (Pluie > Vent > Gel), "rain,frost,wind" (Pluie > Gel > Vent), "frost,wind,rain" (Gel > Vent > Pluie), "frost,rain,wind" (Gel > Pluie > Vent) Ordre des alarmes météo quand plusieurs sont actives : la première active s'applique.
    safetyPriority string "alarms,lock,forced" "alarms,lock,forced" (Alarmes météo > Verrouillage > Forçage), "alarms,forced,lock" (Alarmes météo > Forçage > Verrouillage), "lock,alarms,forced" (Verrouillage > Alarmes météo > Forçage), "lock,forced,alarms" (Verrouillage > Forçage > Alarmes météo), "forced,lock,alarms" (Forçage > Verrouillage > Alarmes météo), "forced,alarms,lock" (Forçage > Alarmes météo > Verrouillage) Ordre des alarmes météo, du verrouillage et du forçage quand plusieurs sont actifs : le premier actif tient la sortie, et les commandes sont ignorées.
    alarmMonitoringMs integer 0 ≥ 0 Les capteurs météo envoient leur alarme cycliquement : sans télégramme sur un objet d'alarme dans ce délai, l'alarme est supposée (0 : pas de surveillance).
    afterAlarm string "none" "none" (Aucun mouvement), "up" (Montée), "down" (Descente), "restore" (Position avant l'alarme) Mouvement à la fin de la dernière alarme météo.
    afterForcing string "none" "none" (Aucun mouvement), "up" (Montée), "down" (Descente), "restore" (Position avant le forçage) Mouvement à la fin du forçage (0 ou 1 sur l'objet de forçage).
    preset1Pct number 20 ≥ 0 ; ≤ 100 Position rappelée par 0 sur l'objet des positions 1/2.
    preset2Pct number 40 ≥ 0 ; ≤ 100 Position rappelée par 1 sur l'objet des positions 1/2.
    preset3Pct number 60 ≥ 0 ; ≤ 100 Position rappelée par 0 sur l'objet des positions 3/4.
    preset4Pct number 80 ≥ 0 ; ≤ 100 Position rappelée par 1 sur l'objet des positions 3/4.
    presetStoring boolean true Les objets de mémorisation remplacent une position mémorisée par la position estimée actuelle, jusqu'au redémarrage de la simulation.
    lockStart string "none" "none" (Aucune réaction), "up" (Montée), "down" (Descente), "stop" (Arrêt), "position" (Position) Mouvement quand l'objet de verrouillage reçoit 1 ; l'alarme vent reste prioritaire.
    lockPositionPct number 0 ≥ 0 ; ≤ 100 Position atteinte au début du verrouillage, avec « Position ».
    afterLock string "none" "none" (Aucune réaction), "up" (Montée), "down" (Descente), "restore" (Position avant le verrouillage) Mouvement quand l'objet de verrouillage reçoit 0.
    busFailure string "stop" "stop" (Arrêt), "up" (Montée), "down" (Descente) Moteur à la coupure de la tension bus : arrêté, ou entraîné vers une fin de course jusqu'au retour de la tension ; la position estimée suit le temps écoulé.
    busRecovery string "none" "none" (Aucun mouvement), "up" (Montée), "down" (Descente), "position" (Position) Mouvement au retour de la tension bus ; la position estimée est envoyée dans tous les cas.
    busRecoveryPositionPct number 0 ≥ 0 ; ≤ 100 Position atteinte au retour du bus, avec « Position ».

    État initial du canal (channels[].initialState)

    Paramètre Type Défaut Contraintes Description
    estimatedPositionPct number 0 ≥ 0 ; ≤ 100 Position que l'actionneur suppose au démarrage (0 = entièrement ouvert, 100 = entièrement fermé) ; le volet raccordé démarre à sa propre position.
    estimatedSlatPct number 0 ≥ 0 ; ≤ 100 Angle des lamelles que l'actionneur suppose au démarrage (stores à lamelles).

    #display/v1

    Afficheur / superviseur : reçoit et affiche des valeurs, sans sortie ni réémission.

    Ports

    Port DPT Canal Rôle
    display tous aucune Valeur reçue et affichée, comme par un voyant ou un superviseur.

    Aucun paramètre.

    #passive/v1

    Appareil sans logique : il garde les valeurs de ses objets et envoie les valeurs saisies dans le schéma, comme un panneau de visualisation. Utilise des touches et des entrées.

    Ports

    Port DPT Canal Rôle
    input tous aucune Objet écrit par une entrée numérique du schéma, puis transmis.
    display tous aucune Valeur reçue et conservée, telle qu'une visualisation l'affiche.

    Aucun paramètre.

    #presenceDetector/v1

    Détecteur de présence : envoie 1 à la première détection, 0 à la fin de sa temporisation (relancée à chaque détection). Utilise des touches et des entrées.

    Ports

    Port DPT Canal Rôle
    input 1.001, 1.018 aucune objet de sortie : 1 à la détection, 0 à l'expiration de la temporisation
    lock 1.001 aucune 1 verrouille le détecteur : ses détections (et celles de ses esclaves) sont ignorées ; 0 le déverrouille
    slaveTrigger 1.001, 1.018 aucune 1 envoyé par un détecteur esclave de la même pièce : compte comme une détection (fonctionnement maître/esclave)
    brightness 9.004 aucune luminosité mesurée (lx), saisie par le lecteur et envoyée ; il n'y a pas de modèle d'éclairement

    Paramètres de l'appareil (parameters)

    Paramètre Type Défaut Contraintes Description
    lockStart string "none" "none" (Aucun télégramme), "off" (Arrêt), "on" (Marche) Télégramme quand l'objet de verrouillage reçoit 1 : aucun (la temporisation s'écoule normalement), 0 immédiatement, ou 1 maintenu pendant le verrouillage. Pendant le verrouillage, les détections sont ignorées.
    lockEnd string "none" "none" (Aucun télégramme), "off" (Arrêt), "on" (Marche) Télégramme quand l'objet de verrouillage reçoit 0 : aucun, 0, ou 1 suivi de la temporisation.
    slave boolean false Envoie 1 à chaque détection, pour l'objet slaveTrigger d'un détecteur maître de la même pièce ; le maître garde la temporisation, le seuil de luminosité et le 0 final.
    holdMs integer 10000 > 0 Durée sans présence détectée avant l'envoi de 0 (ms) ; relancée à chaque détection.
    retrigger boolean true Chaque activation relance la temporisation ; sinon elle court depuis la première activation.
    sendOnEnd boolean true Envoyer 0 à l'expiration de la temporisation ; sinon le détecteur n'envoie que 1 et l'actionneur gère l'extinction.
    brightnessThresholdLux number 0 ≥ 0 Une détection n'allume que tant que la luminosité saisie est inférieure à cette valeur (lx) ; une présence active est quand même prolongée. 0 désactive le seuil.

    #usbInterface/v1

    Interface USB : écrit et lit des adresses de groupe depuis le panneau de l'interface USB du schéma.

    Ports

    Port DPT Canal Rôle

    Paramètres de l'appareil (parameters)

    Paramètre Type Défaut Contraintes Description
    groupAddresses string "" Adresses de groupe affectées à cette interface dans le projet, séparées par des espaces ou des virgules. Les tables de filtrage des coupleurs les incluent : les télégrammes sur ces adresses traversent les coupleurs vers l'interface et depuis elle.     #dimmerActuator/v1

    Variateur : commutation, variation relative (3.007) et absolue (5.001), blanc variable (7.600), retour d'état. Commande de sortie : dim.

    Ports

    Port DPT Canal Rôle
    switch 1.001 obligatoire Commande de commutation du canal (0 = arrêt, 1 = marche).
    dim 3.007 obligatoire Variation relative (3.007) : bit de sens et pas de 1 à 7 ; 0 arrête la variation.
    value 5.001 obligatoire Valeur de luminosité en pourcentage (5.001) ; zéro éteint.
    status 1.001 obligatoire État de commutation du canal, envoyé après chaque changement.
    valueStatus 5.001 obligatoire Valeur de luminosité (5.001), envoyée après une transition.
    scene 17.001, 18.001 facultatif (tous les canaux s'il est omis) numéro de scène (17.001), ou commande de scène (18.001) dont le bit d'apprentissage mémorise le niveau actuel
    colourTemperature 7.600 obligatoire consigne de température de couleur (K) d'un canal à blanc variable
    colourTemperatureStatus 7.600 obligatoire température de couleur appliquée (K)

    Paramètres de canal (channels[].parameters)

    Paramètre Type Défaut Contraintes Description
    onLevel string "fixed" "fixed" (Valeur réglée), "last" (Dernière valeur) Niveau à l'allumage : fixed utilise onLevelPct ; last rétablit le niveau d'avant l'extinction.
    onLevelPct number 100 ≥ 1 ; ≤ 100 Niveau atteint quand une valeur 1 est reçue (mode fixe).
    dimTimeMs integer 5000 > 0 Durée d'une variation relative de 0 à 100 % (DPT 3.007) ; des pas plus petits prennent moins de temps.
    switchFadeMs integer 0 ≥ 0 Durée de transition à l'allumage ou à l'extinction (0 signifie immédiat).
    sceneLearning boolean true Un télégramme de commande de scène avec le bit d'apprentissage (DPT 18.001) mémorise le niveau actuel comme scène ; il remplace le préréglage configuré jusqu'au redémarrage de la simulation.
    valueFadeMs integer 0 ≥ 0 Durée de transition vers une valeur reçue (5.001) ou un préréglage de scène.
    minLevelPct number 1 ≥ 0 ; ≤ 50 Niveau minimal de la variation relative.
    maxLevelPct number 100 ≥ 50 ; ≤ 100 Limite haute pour la variation relative et les valeurs reçues.
    dimSwitchesOn boolean true Une commande d'augmentation allume un canal éteint.
    dimSwitchesOff boolean false Une commande de diminution peut faire varier jusqu'à l'extinction ; sinon elle s'arrête au niveau minimal.
    valueSwitchesOn boolean true Une valeur de luminosité supérieure à 0 allume un canal éteint ; sinon la valeur est ignorée tant que le canal est éteint.
    valueSwitchesOff boolean true Une valeur de luminosité de 0 éteint le canal ; sinon le canal descend à son niveau minimal.
    statusDelayMs integer 300 ≥ 0 Délai avant l'envoi du retour d'état (ms), une fois une transition terminée.
    busFailure string "unchanged" "unchanged" (Inchangé), "off" (Arrêt), "level" (Niveau fixe) Niveau du canal à la coupure de la tension bus ; il est ensuite gardé jusqu'au retour de la tension.
    busFailureLevelPct number 100 ≥ 0 ; ≤ 100 Niveau appliqué à la coupure de la tension bus, avec « Niveau fixe ».
    busRecovery string "previous" "previous" (Niveau avant la coupure), "off" (Arrêt), "on" (Marche) Niveau du canal au retour de la tension bus (marche : le niveau d'allumage) ; le retour d'état est alors envoyé.
    minColourK integer 2700 ≥ 1000 ; ≤ 10000 Température de couleur la plus basse (K) d'un canal à blanc variable ; les demandes inférieures y sont ramenées.
    maxColourK integer 6500 ≥ 1000 ; ≤ 10000 Température de couleur la plus haute (K) d'un canal à blanc variable ; les demandes supérieures y sont ramenées.

    État initial du canal (channels[].initialState)

    Paramètre Type Défaut Contraintes Description
    levelPct number 0 ≥ 0 ; ≤ 100 Niveau de la sortie au démarrage de la simulation ; 0 signifie éteinte.
    colourTemperatureK integer 4000 ≥ 1000 ; ≤ 10000 Température de couleur (K) au démarrage, pour un canal qui a un objet colourTemperature.

    #daliGateway/v1

    Passerelle KNX/DALI : chaque canal est un groupe DALI de ballasts ; diffusion générale, scènes et signalement des défauts. Commande de sortie : dim.

    Ports

    Port DPT Canal Rôle
    switch 1.001 obligatoire Commande de commutation du canal (0 = arrêt, 1 = marche).
    dim 3.007 obligatoire Variation relative (3.007) : bit de sens et pas de 1 à 7 ; 0 arrête la variation.
    value 5.001 obligatoire Valeur de luminosité en pourcentage (5.001) ; zéro éteint.
    status 1.001 obligatoire État de commutation du canal, envoyé après chaque changement.

    #buttonInterface/v1

    Interface de boutons-poussoirs : chaque canal est une entrée de contact avec une fonction (commutation, variation, store, valeur, scène), avec appuis courts et longs ; verrouillage, retour de la tension bus et envoi cyclique.

    Ports

    Port DPT Canal Rôle
    switch 1.001, 1.002, 1.003, 1.005, 1.007, 1.008, 1.009, 1.010, 1.011, 1.012, 1.015, 1.017, 1.018, 1.019, 1.022, 1.100 obligatoire télégrammes de commutation ; avec W activé, l'objet suit l'état de la charge pour que la bascule et la variation sur une touche partent de l'état réel
    dim 3.007 obligatoire Variation relative envoyée par l'entrée (3.007) : un pas pour monter ou baisser, puis un arrêt au relâchement.
    move 1.008 obligatoire mouvement du store ; avec W activé, une entrée sur une touche prend le sens du dernier mouvement reçu
    stopStep 1.007 obligatoire Arrêt ou pas envoyé par l'entrée (1.007).
    value 2.001, 5.001, 5.004, 5.010, 7.600, 9.001, 17.001, 18.001, 20.102 obligatoire valeur envoyée par la fonction Valeur, ou numéro de scène (17.001) ou commande de scène avec mémorisation (18.001) pour la fonction Scène
    lock 1.001 obligatoire 1 verrouille l'entrée (les appuis sont ignorés), 0 la déverrouille
    led 1.001 obligatoire état affiché par la LED de la touche

    Paramètres de canal (channels[].parameters)

    Paramètre Type Défaut Contraintes Description
    function string "switch" "switch" (Commutation), "dim" (Variation), "blind" (Store), "value" (Valeur), "scene" (Scène) Ce que l'entrée commande ; les objets de groupe et les réglages en dépendent.
    longPressMs integer 500 ≥ 100 ; ≤ 10000 Un appui maintenu au moins ce temps est un appui long.
    switchLongPress boolean false Distinguer appuis courts et longs, avec une action pour chacun ; sinon une action à l'appui et une au relâchement.
    onPress string "toggle" "on" (Marche), "off" (Arrêt), "toggle" (Inverser), "none" (Aucune action) Télégramme de commutation à la fermeture du contact.
    onRelease string "none" "on" (Marche), "off" (Arrêt), "toggle" (Inverser), "none" (Aucune action) Télégramme de commutation à l'ouverture du contact.
    onShort string "toggle" "on" (Marche), "off" (Arrêt), "toggle" (Inverser), "none" (Aucune action) Télégramme de commutation après un appui court, au relâchement de la touche.
    onLong string "none" "on" (Marche), "off" (Arrêt), "toggle" (Inverser), "none" (Aucune action) Télégramme de commutation quand la durée d'appui long est atteinte.
    dimMode string "single" "single" (Une touche : marche/arrêt, plus clair et plus sombre tour à tour), "brighter" (Deux touches : cette touche allume et éclaircit), "darker" (Deux touches : cette touche éteint et assombrit) Une touche commute par un appui court et fait varier par un appui long, plus clair quand l'éclairage est éteint et sinon dans le sens inverse de la fois précédente ; deux touches se partagent le travail, l'une plus clair et l'autre plus sombre. Le relâchement de la touche arrête la variation.
    dimStep integer 1 1 (100 %), 2 (50 %), 3 (25 %), 4 (12.5 %), 5 (6 %), 6 (3 %), 7 (1.5 %) Code de pas du télégramme de variation relative (DPT 3.007) ; 100 % fait varier jusqu'au relâchement de la touche.
    blindMode string "single" "single" (Une touche : montée et descente tour à tour), "up" (Deux touches : cette touche monte), "down" (Deux touches : cette touche descend) Un appui long déplace le store et un appui court l'arrête ou fait un pas ; avec une touche, le sens change à chaque mouvement, et suit l'objet montée/descente quand il reçoit un télégramme.
    stopOnRelease boolean false Relâcher la touche après un appui long arrête le store (maintenir pour déplacer) ; sinon le store va jusqu'en fin de course à moins qu'un appui court ne l'arrête.
    shortValue number 0 Valeur envoyée par un appui court (par tout appui quand il n'y a pas de valeur d'appui long), dans l'unité du DPT de l'objet.
    longValue number null null
    sceneNumber integer 1 ≥ 1 ; ≤ 64 Scène rappelée par un appui court.
    sceneStore boolean false Un appui long demande aux actionneurs de mémoriser leur état actuel comme scène (DPT 18.001, bit d'apprentissage) ; un appui court la rappelle.
    lockStart string "none" "none" (Aucune réaction), "on" (Marche), "off" (Arrêt) Télégramme de commutation envoyé quand l'objet de verrouillage reçoit 1.
    lockEnd string "none" "none" (Aucune réaction), "update" (Envoyer la valeur actuelle), "on" (Marche), "off" (Arrêt) Télégramme de commutation envoyé quand l'objet de verrouillage reçoit 0.
    blindLockStart string "none" "none" (Aucune réaction), "up" (Montée), "down" (Descente) Mouvement envoyé quand l'objet de verrouillage reçoit 1.
    blindLockEnd string "none" "none" (Aucune réaction), "up" (Montée), "down" (Descente) Mouvement envoyé quand l'objet de verrouillage reçoit 0.
    busRecovery string "none" "none" (Aucune réaction), "update" (Envoyer la valeur actuelle), "on" (Marche), "off" (Arrêt) Télégramme de commutation envoyé au retour de la tension bus après une coupure.
    blindBusRecovery string "none" "none" (Aucune réaction), "up" (Montée), "down" (Descente) Mouvement envoyé au retour de la tension bus après une coupure.
    busRecoveryDelayMs integer 0 ≥ 0 Délai avant la réaction au retour du bus, pour que les appareils d'une ligne n'émettent pas tous en même temps.
    cyclicMs integer null null > 0
    cyclicWhen string "always" "always" (Les deux valeurs), "on" (Only 1 (marche)), "off" (Only 0 (arrêt)) Valeur de l'objet de commutation envoyée cycliquement.
    actuatedContact string "closed" "closed" (Contact fermé), "open" (Contact ouvert) État du contact d'entrée quand le bouton-poussoir est actionné : fermé pour un bouton-poussoir normalement ouvert, ouvert pour un bouton normalement fermé.
    ledShown boolean false La touche a une LED : elle affiche l'objet LED quand il est activé, sinon l'objet de commutation d'une entrée de commutation ou de variation.
    ledInverted boolean false La LED est allumée tant que son objet vaut 0 et éteinte tant qu'il vaut 1.

    #alarmModule/v1

    Module d'alarme : pour chaque zone, une alarme intrusion et une alarme incendie activées par un déclencheur, mémorisées jusqu'à une réinitialisation acceptée une fois le déclencheur revenu à 0.

    intrusionState 1.005, 1.001 obligatoire Alarme intrusion mémorisée, envoyée à chaque changement ; reliez-la aux objets d'intrusion des actionneurs
    fireTrigger 1.005, 1.001 obligatoire 1 venant d'un détecteur d'incendie active l'alarme incendie mémorisée
    fireReset 1.015, 1.001 obligatoire 1 réinitialise l'alarme mémorisée, seulement une fois son déclencheur revenu à 0
    fireState 1.005, 1.001 obligatoire Alarme incendie mémorisée, envoyée à chaque changement ; reliez-la aux objets d'incendie des actionneurs
