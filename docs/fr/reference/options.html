    Référence

    #Options d'affichage

    Une option se règle par un attribut HTML (monitor="false") ou par une propriété JavaScript ({ monitor: false }). Les options JavaScript l'emportent. Les valeurs invalides sont ignorées. Les attributs booléens acceptent true, false, ou l'attribut seul pour vrai.

    <bus-diagram fit="contain" toolbar="compact" monitor="false" style="height:520px"></bus-diagram>
    const diagram = BusDiagram.create("#diagram", scenario, {
  fit: "contain",
  toolbar: "compact",
  monitor: false,
});
diagram.options = { monitor: true }; // Change an option later.

    #toolbar

    Attribut HTML Option JavaScript Type Défaut
    toolbar toolbar "full" | "compact" | "none" "full"

    Barre d'outils au-dessus du schéma. ‘full’ affiche le titre, la vitesse, les tables de filtrage, la commande pas à pas, la pause et la réinitialisation. ‘compact’ affiche trois petits boutons flottants dans un coin du schéma, adaptés à une diapositive. ‘none’ masque les commandes tout en laissant le schéma interactif.

    <bus-diagram toolbar="compact">

    #monitor

    Attribut HTML Option JavaScript Type Défaut
    monitor monitor booléen true

    Moniteur de groupe et détail des télégrammes sous le schéma. Mettez false quand une diapositive ou une page n'a besoin que du schéma. Les télégrammes circulent toujours sur le bus.

    <bus-diagram monitor="false">

    #description

    Attribut HTML Option JavaScript Type Défaut
    description description booléen true

    description du scénario sous la barre d'outils. À masquer quand la page ou la diapositive explique déjà l'interaction.

    <bus-diagram description="false">

    #hints

    Attribut HTML Option JavaScript Type Défaut
    hints hints booléen true

    Aide expliquant les appuis courts et longs sur les touches. Affichée seulement quand une touche distingue appuis courts et longs.

    <bus-diagram hints="false">

    #fit

    Attribut HTML Option JavaScript Type Défaut
    fit fit "width" | "contain" "width"

    Mise à l'échelle du schéma. ‘width’ utilise la largeur disponible entre minScale et maxScale ; un schéma trop grand défile horizontalement au lieu de devenir illisible. ‘contain’ fait tenir tout le schéma dans le composant ; donnez au composant une hauteur explicite, par exemple 100 % d'une diapositive.

    <bus-diagram fit="contain" style="height:560px">

    #maxScale

    Attribut HTML Option JavaScript Type Défaut
    max-scale maxScale nombre 1.2

    Échelle maximale du schéma. Évite qu'un petit schéma devienne démesuré sur un grand écran.

    <bus-diagram max-scale="1">

    #minScale

    Attribut HTML Option JavaScript Type Défaut
    min-scale minScale nombre 0.7

    Échelle minimale en mode ‘width’ avant le défilement horizontal. En dessous de cette échelle, les libellés deviendraient illisibles : le schéma défile.

    <bus-diagram min-scale="0.5">

    #speed

    Attribut HTML Option JavaScript Type Défaut
    speed speed nombre options.speed du scénario, sinon 1

    Vitesse initiale de la simulation. 1 est le temps réel, 0.35 plus lent et 2 plus rapide. Le seuil d'appui long (0,5 seconde réelle) ne change pas.

    <bus-diagram speed="0.35">

    #stepMode

    Attribut HTML Option JavaScript Type Défaut
    step-mode stepMode booléen false

    Démarrer en mode pas à pas. S'arrête à chaque émission, décision de coupleur, réception, changement de sortie et événement programmé, avec une explication et un bouton Suivant.

    <bus-diagram step-mode>

    #designer

    Attribut HTML Option JavaScript Type Défaut
    designer designer URL | "none" le designer publié

    Designer ouvert par l'icône de la barre d'outils. L'icône ouvre le designer dans un nouvel onglet avec le scénario, transporté compressé dans le lien après #, qui n'est pas envoyé au serveur. Donnez l'adresse d'une copie du designer (par exemple un chemin relatif, pour travailler hors ligne), ou none pour masquer l'icône. Masquée quand la barre d'outils l'est.

    <bus-diagram designer="designer/index.html">

    #timeline

    Attribut HTML Option JavaScript Type Défaut
    timeline timeline identifiants de traces | true masqué

    Chronogramme d'au plus quatre traces sur l'axe du temps simulé. Affiche les valeurs d'objets et les états marche/arrêt en escalier, les températures des pièces, les ouvertures et les niveaux en courbes, et les télégrammes d'un objet tracé en marques. Indiquez les premières traces : device/object pour un objet, device:channel pour l'équipement d'une sortie, @room pour la température d'une pièce ; sans liste (ou avec true), le chronogramme démarre vide. Un menu ajoute ou retire des traces.

    <bus-diagram timeline="livingThermostat/temp @livingRoom">
