    #Ports

    A communication object's port names its role in a device behavior. Each behavior accepts specific ports and DPTs; see behaviors.

    Port Description Behaviors
    switch Switching command of the output (0 = off, 1 = on). switchActuator/v1, dimmerActuator/v1, daliGateway/v1, heatingActuator/v1, buttonInterface/v1
    status Status of the relay, sent after each effective change. switchActuator/v1, dimmerActuator/v1, daliGateway/v1
    scene scene number (17.001), or scene control (18.001) whose learn bit stores the current state switchActuator/v1, shutterActuator/v1, dimmerActuator/v1, daliGateway/v1
    forced Priority override (2 = force off, 3 = force on, 0 or 1 = end of the override). switchActuator/v1, shutterActuator/v1
    lock 1 locks the output in the state set by lockStart, 0 unlocks it (afterLock) switchActuator/v1, shutterActuator/v1, presenceDetector/v1, buttonInterface/v1
    logic combined with the switching command by logicOperation (AND or OR) switchActuator/v1
    power electrical power drawn by the load of the channel: W with 14.056, kW with 9.024 switchActuator/v1, energyMeter/v1
    energy active energy counted for the channel, sent cyclically: Wh with 13.010, kWh with 13.013 switchActuator/v1, energyMeter/v1
    totalPower sum of the power of all channels: W with 14.056, kW with 9.024 switchActuator/v1, energyMeter/v1
    powerLimit 1 when the total power reaches powerLimitW, 0 after hysteresis (load shedding) switchActuator/v1
    intrusionAlarm 1 makes the output blink and ignore the commands; 0 ends the alarm (afterAlarm). Without channel, applies to all channels. switchActuator/v1
    fireAlarm 1 forces the output on and ignores the commands, with priority over intrusion; 0 ends the alarm. Without channel, applies to all channels. switchActuator/v1
    move Up/down: 0 raises toward 0 %, 1 lowers toward 100 %. shutterActuator/v1, buttonInterface/v1
    stopStep Stop when moving; otherwise one step of stepPct (0 up, 1 down). shutterActuator/v1, buttonInterface/v1
    positionCommand Target position in percent. shutterActuator/v1
    positionStatus Estimated position, sent after stopping. shutterActuator/v1
    slatCommand slat angle (0 % open, 100 % closed) of a venetian blind shutterActuator/v1
    slatStatus estimated slat angle, sent after stopping shutterActuator/v1
    windAlarm 1 starts the wind alarm (windReaction, up by default): commands are ignored until 0; without channel, applies to all channels shutterActuator/v1, weatherStation/v1
    rainAlarm 1 starts the rain alarm (rainReaction); 0 ends it shutterActuator/v1, weatherStation/v1
    frostAlarm 1 starts the frost alarm (frostReaction); 0 ends it shutterActuator/v1, weatherStation/v1
    recallPosition12 0 moves to the stored position 1, 1 to the stored position 2 shutterActuator/v1
    recallPosition34 0 moves to the stored position 3, 1 to the stored position 4 shutterActuator/v1
    storePosition12 0 stores the current position as position 1, 1 as position 2 shutterActuator/v1
    storePosition34 0 stores the current position as position 3, 1 as position 4 shutterActuator/v1
    upperLimit 1 when the shutter is estimated at the top (0 %), sent on change shutterActuator/v1
    lowerLimit 1 when the shutter is estimated at the bottom (100 %), sent on change shutterActuator/v1
    display Value received and shown, as by an indicator or a supervisor. display/v1, passive/v1
    input Object written by a numeric input of the diagram, then transmitted. passive/v1, presenceDetector/v1
    slaveTrigger 1 sent by a slave detector of the same room: counts as a detection (master/slave operation) presenceDetector/v1
    brightness measured brightness (lx), entered by the reader and sent; there is no light model presenceDetector/v1, weatherStation/v1
    dim Relative dimming (3.007): direction bit and step size 1–7; 0 stops dimming. dimmerActuator/v1, daliGateway/v1, buttonInterface/v1
    value Brightness value in percent (5.001); zero switches off. dimmerActuator/v1, daliGateway/v1, heatingActuator/v1, systemGateway/v1, buttonInterface/v1
    valueStatus Brightness value (5.001), sent after a transition. dimmerActuator/v1, daliGateway/v1, heatingActuator/v1
    colourTemperature colour temperature setpoint (K) of a tunable white channel dimmerActuator/v1
    colourTemperatureStatus applied colour temperature (K) dimmerActuator/v1
    error lamp or ballast fault in the group daliGateway/v1
    broadcastSwitch Switches all groups with a DALI broadcast. daliGateway/v1
    broadcastValue Sets the level of all groups with a DALI broadcast. daliGateway/v1
    generalError Fault on the DALI line, across all groups (1.005). daliGateway/v1
    actualTemp Measured temperature (9.001), sent on change. roomThermostat/v1
    sensorFault 1 when no temperature is usable (external temperature too old and no room sensor); 0 when one comes back roomThermostat/v1
    externalTemp replaces the internal sensor after a value is received roomThermostat/v1
    baseSetpoint Base comfort setpoint for heating (9.001). roomThermostat/v1
    setpointShift base setpoint = configured setpoint + offset roomThermostat/v1
    setpointStatus Current setpoint (9.001). roomThermostat/v1
    hvacMode Selected mode (20.102: 0 auto, 1 comfort, 2 standby, 3 economy, 4 protection). roomThermostat/v1
    comfortMode 1 selects comfort, which has priority over night; with the other 1-bit mode objects, replaces the 1-byte preselection roomThermostat/v1
    nightMode 1 selects night (economy), 0 standby, unless comfort or protection is 1 roomThermostat/v1
    protectionMode 1 selects frost or heat protection, which has priority over comfort and night roomThermostat/v1
    forcedMode 1–4 forces comfort, standby, economy, or protection over everything else, the window included; 0 (auto) ends the forcing roomThermostat/v1
    hvacModeStatus Current mode (20.102). roomThermostat/v1
    presence 1 = presence: comfort mode roomThermostat/v1
    window open window (1.019 / 1.001: 1 = open; 1.009: 0 = open): protection mode, over everything but the forced mode roomThermostat/v1
    heatCool 1 = heating, 0 = cooling; not used with the automatic change-over roomThermostat/v1, heatingActuator/v1
    heatCoolStatus Current mode: 1 heating, 0 cooling (1.100). roomThermostat/v1
    heatingValue continuous control value from 0 to 100% roomThermostat/v1
    heatingSwitch two-point control, or PWM under PI control roomThermostat/v1
    coolingValue Continuous cooling control value (5.001). roomThermostat/v1, heatingActuator/v1
    coolingSwitch One-bit cooling command. roomThermostat/v1, heatingActuator/v1
    controlValue control value of the active mode, heating or cooling, on one object (2-pipe system); heatCoolStatus tells which roomThermostat/v1
    controlSwitch one-bit control of the active mode, heating or cooling, on one object (2-pipe system) roomThermostat/v1
    fault missing control value: fallback program heatingActuator/v1
    contact 1.019 / 1.001: 1 means open; 1.009: 1 means closed windowContact/v1
    temperature Room temperature (9.001). temperatureSensor/v1, airQualitySensor/v1
    logicIn one-bit input of the logic function logicGate/v1
    enable 0 blocks the output; 1 enables it again and sends the current result logicGate/v1
    time time received from a clock master, used by the time window logicGate/v1, clockMaster/v1
    logicOut result of the logic function logicGate/v1
    wind measured wind speed, sent when entered: m/s with 9.005, km/h with 9.028 (thresholds stay in m/s) weatherStation/v1
    outdoorTemp measured outdoor temperature (°C), sent when entered weatherStation/v1
    sunProtection 1 when the brightness threshold is reached, 0 after hysteresis weatherStation/v1
    humidity measured relative humidity (%), sent when entered: 2-byte float with 9.007, one byte with 5.001 airQualitySensor/v1
    co2 measured CO₂ concentration (ppm), sent when entered airQualitySensor/v1
    co2Alarm 1 when the CO₂ alarm threshold is reached, 0 after hysteresis airQualitySensor/v1
    humidityAlarm 1 when the humidity alarm threshold is reached, 0 after hysteresis airQualitySensor/v1
    ventilation control value (%) of the current ventilation step airQualitySensor/v1
    date date of the simulated clock clockMaster/v1
    output object that receives the programmed values timeSwitch/v1
    override Value sent at once on the output, held until the next switching point of the program timeSwitch/v1
    overrideTimed Value sent at once on the output, held for overrideDurationMin clock minutes; the program value then applies timeSwitch/v1
    overridePermanent 1 suspends the program (switching points ignored); 0 resumes it and sends its current value timeSwitch/v1
    command value received from KNX and forwarded to the other system (mode, setpoint, boost…) systemGateway/v1
    led state shown by the LED of the key buttonInterface/v1
    intrusionTrigger 1 from an intrusion contact or detector sets the stored intrusion alarm alarmModule/v1
    intrusionReset 1 resets the stored alarm, only once its trigger has returned to 0 alarmModule/v1
    intrusionState Stored intrusion alarm, sent on each change; link it to the intrusion objects of the actuators alarmModule/v1
    fireTrigger 1 from a fire detector sets the stored fire alarm alarmModule/v1
    fireReset 1 resets the stored alarm, only once its trigger has returned to 0 alarmModule/v1
    fireState Stored fire alarm, sent on each change; link it to the fire objects of the actuators alarmModule/v1
