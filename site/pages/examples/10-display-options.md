# Display options

This embed uses a compact toolbar, hides the monitor and description, and slows the simulation. These settings suit a page that provides its own explanation. See the [display options reference](../reference/options.html).

```knx
scenario: status-feedback
attrs: toolbar="compact" monitor="false" description="false" speed="0.35"
```
