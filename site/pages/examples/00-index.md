# Examples

Each example is a diagram of a typical installation or an integration pattern. Every example page shows the diagram, which can be operated, with **HTML** and **JSON** tabs to inspect or copy the code and a link to open it in the [designer](../designer/index.html). The scenario files are also published as JSON in the `scenarios/` directory of the site.
