# Référence

Ces pages documentent les options d'affichage, les champs des scénarios, les définitions des comportements, les méthodes de l'API, les événements et les erreurs. Les tableaux indiqués comme générés proviennent du schéma de rédaction ou des définitions enregistrées. Le moteur vérifie aussi des règles entre champs, comme les références et la compatibilité des DPT, qu'un schéma JSON ne peut pas exprimer entièrement.
