# Exemples

Chaque exemple est le schéma d'une installation type ou d'un modèle d'intégration. Chaque page d'exemple montre le schéma, que l'on peut manipuler, avec des onglets **HTML** et **JSON** pour examiner ou copier le code, et un lien pour l'ouvrir dans le [designer](../designer/index.html). Les fichiers de scénario sont aussi publiés en JSON dans le dossier `scenarios/` du site.
